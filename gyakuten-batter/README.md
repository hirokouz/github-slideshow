# 逆転バッター（GYAKUTEN BATTER）プロトタイプ

スマホ向けの「1タップ・バッティング × ローグライト」。`index.html` をブラウザで開けばそのまま遊べます。

- いつも 9回裏・負けている場面から始まり、3アウトまでに目標の点を取ればサヨナラ勝ち
- タップでスイング。球がベースに届く瞬間ぴったりならホームラン、早いと引っぱり・遅いと流し打ち
- ボール球は見送り（振るとタイミングの幅が狭くなる）。B/S/O・ランナーは本物の野球ルール
- 5人の投手（球種・球速がそれぞれ違う）を順に倒すと優勝
- 勝つたびにカード（10種）を1枚選んで打者を強化。メダルで永続強化（3種）

## 売るための次の一手
1. 5〜10人に遊んでもらい、「もう1回」と言うか・難しさが合っているかを確認
2. Capacitor で iOS/Android アプリ化
3. 収益化: リワード広告（負けた試合をもう1アウト延長・メダル2倍）＋広告削除の買い切り
4. 追加要素: 打者キャラの種類、球場、毎日変わる「今日の投手」チャレンジ

`game.html` は Artifact 公開用（html/head タグなし）、`index.html` は単体で動く版です。
