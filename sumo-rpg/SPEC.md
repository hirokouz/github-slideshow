# 横綱への道 仕様書

スマホ向けの相撲キャリア育成RPG。新弟子として入門し、稽古と本場所をくり返して横綱を目指す。引退後は部屋の格を上げ、次の弟子（二代目もあり）へつなぐ。

- 遊ぶ場所：`index.html`（単体で動く）／公開版 https://yokozuna.j2prco.workers.dev/
- 保存：ブラウザの中に自動保存（LINEとChromeなど、ブラウザが違うとデータは別）
- 画像：ChatGPTで作った絵（力士・女性・タニマチ）、音楽：Sunoで作った3曲（タイトル・稽古場・取組）

---

## 1. 1場所の流れ

1. **稽古期間（5回）** 稽古場で行動を5回選ぶ
2. **本場所** 幕下以下は7番、十両以上は15番。1日1番
3. **場所の結果** 勝ち越し・負け越し・優勝・三賞・番付の上下
4. **イベント** 昇進のお祝い、恋愛、タニマチ、宿敵など（起きたものだけ順に出る）
5. 年末（九州場所のあと）は**帰省**のイベント

1年は6場所（初・春・夏・名古屋・秋・九州）。

## 2. 力士をつくる

| 項目 | 内容 |
|---|---|
| 入門の年齢 | 15歳（伸びしろ最大）／18歳（やや強い）／22歳（三段目付出デビュー、伸びは早く止まる） |
| 型 | 押し相撲（押しが強い）／四つ相撲（力が強く体が大きい）／技能派（小柄で速い） |
| 顔・しこ名・出身地 | 選べる。出身地は47都道府県とモンゴル |
| モンゴル出身 | モンゴル相撲（ブフ）の経験で、**技がはじめからC**（55〜58）。技の伸びしろも少し高い |

### 能力
- **押し・力・技・速さ** と **体重**。ランクは F → E → D → C → B → A → S（25・40・55・70・85・100 で上がる）
- 能力ごとに**伸びしろ（上限）**があり、型でちがう
- 年齢で伸び方が変わる：20歳まで「伸び盛り」→ 25「充実期」→ 29「円熟期」→ 32「ベテラン」→「晩年」
- **疲れ**：60をこえると取組で弱くなり、けがをしやすい

## 4. 本場所・取組

- 取組ごとに**作戦**を選ぶ：押し／四つ／技（押し→四つ→技→押し の三すくみ）
- **立ち合い**：タイミングよくタップ
- **ミニゲーム**（オフにもできる）
  - 押し：3秒間の連打
  - 四つ：動く針をゾーンで止める
  - 技：矢印に反応してかわす
  - 土俵際：連打で残す
- 決まり手は43種類＋勇み足などの非技4種類（珍しい技もある）。出した決まり手は図鑑に記録

### 取組の相手（実際の取組表に近い順番）
| 自分の番付 | 当たり方 |
|---|---|
| 横綱 | 序盤は小結・前頭上位、中盤から関脇・大関、終盤はほぼ大関、千秋楽は横綱か大関 |
| 大関 | 横綱と同じ流れ。終盤に横綱と当たる |
| 関脇・小結 | 終盤に横綱・大関 |
| 前頭5枚目まで | 序盤に上位陣 |
| 前頭中位〜下位 | 近い番付。終盤に勝ち星が多いと上位と組まれる。幕内の下のほうは十両上位とも |
| 十両 | 近い番付。ときどき幕内・幕下と |
| 幕下以下 | 近い番付 |
| 前相撲 | 新弟子どうし |

- **宿敵**とは場所の中日に当たる。ふたりとも大関以上なら**千秋楽の結びの一番**
- けががひどいと途中休場・全休

## 5. 番付

序ノ口 → 序二段 → 三段目 → 幕下 → 十両（ここから関取）→ 前頭（幕内）→ 小結 → 関脇 → 大関 → 横綱

- 勝ち越せば上がる、負け越せば下がる（実際の番付の動きに近い枚数）
- 東が西より半枚上。三役は「東」で表示
- **大関昇進**：三役で3場所33勝が目安（その場所10勝以上）
- **大関**：負け越すと次はカド番。カド番で負け越すと関脇へ陥落。陥落直後の場所で10勝すれば大関に戻る
- **横綱昇進**：大関で2場所続けて「優勝か13勝以上」、さらに**全能力がA（85）以上**。力が足りないと決定戦で負けて綱を逃す
- 横綱は下がらない。成績が悪いと進退問題（引退の話）

## 7. ご祝儀・ガチャ・カード・道具

- **ご祝儀**：勝ち星・勝ち越し・優勝・三賞・タニマチ・イベント・実績・ログインボーナス（毎日100、7日目は500）でもらえる
- ご祝儀は**力士ごとの財布**。新弟子は支度金300から始まる。ガチャ・ログインボーナス・実績のご祝儀は、いま育てている力士の財布に入る。二代目は父のご祝儀を全額受け継ぐ。力士がいないあいだのログインボーナスなどは部屋で預かり、次の新弟子に渡す
- **ガチャ**：1回100、10連900。出る確率 SSR 3%／SR 12%／R 35%／N 50%
- **サポートカード**（16種類）：3枚まで付けられ、稽古や取組に効く。重なると強化（最大Lv5）
- **道具（秘伝書・極意書）**：稽古場から引いたSR・SSRの6回に1回くらい。能力のランクが1つ（秘伝書）／2つ（極意書）上がる。引いた力士本人の持ち物（二代目には受け継がれる）

## 8. 人とのつながり

### 宿敵
- 入門の日に同じ土俵で向き合った同期。いっしょに番付を上がっていく
- 自分が大関になると宿敵も強くなり、**大関 → 横綱**を目指す
- 宿敵が横綱になるとイベント「宿敵が横綱に」。以後、千秋楽の結びで**横綱決戦**
- 宿敵の妹（千夏）と恋人になることもある

### 恋愛・結婚（6人）
| 相手 | 出会い | 結婚したときの支え |
|---|---|---|
| 幼なじみの遥 | 帰省先で再会（帰省イベントで連絡先を交換） | 取組の力+1、負け越した場所のあと疲れが全回復 |
| 後援会長の娘・綾乃 | 地元後援会の集まり（帰省イベント「後援会の結成」） | ご祝儀+20% |
| 管理栄養士の真緒 | ちゃんこ番を手伝いに来た（ちゃんこ12回） | 体重が増えやすく、けがをしにくい |
| 宿敵の妹・千夏 | 宿敵の紹介（宿敵に5勝） | 宿敵との取組で力+2 |
| 部屋の手伝いの紗季 | 朝稽古のあと手伝っている（稽古60回） | 稽古の伸び+10% |
| 相撲記者の奈央子 | 関取昇進の取材（十両に上がる） | 初めて当たる相手との取組で力+2（二代目の息子は+1） |

- 出会いは18歳から。18歳になったとき（別れたあとも）6人の中から1人が「運命の相手」としてランダムに決まり、その人の条件を満たすと出会う（遥・綾乃はその人の帰省イベントが先に出る）。12場所たっても出会えないときは、条件を満たしている人の中から出会う。6人とも出会いやすさはほぼ同じ
- 気になる人 → 告白 → 恋人 → プロポーズ（関取で20歳以上）→ 婚約 → 結婚式 → 子ども
- デートしないと親密度が下がり、別れることもある
- **失恋・離婚の絶不調**：彼女・婚約者と別れると次の場所は絶不調（取組の力 −5）。離婚すると**ご祝儀を全額失い**（慰謝料）、1年間絶不調（取組の力 −5・稽古の伸び −20%）
- **二股**（恋人・婚約者・妻のどの時期でも）
  - 帰省先で幼なじみの遥と再会する、または場所後に**元恋人や別のヒロインから誘われる**（10%／場所）。「こっそり会う」と二股になる
  - 二股は**早めにバレる**：始めた次の場所で40%、そのあと場所ごとに+20%（4場所目には必ず）。相手にスマホを見られて**修羅場**、または関取（恋人のときは幕内）なら半分の確率で**週刊誌のスクープ**
  - 結婚中に2回バレると**離婚**（部屋に戻って暮らす）
  - スクープの選択：すぐ認めて謝罪会見（軽め）／「事実無根」と否定（うわさで済むか、写真が出てさらに炎上）／親方に頼んで止める（**ご祝儀を全額**使う。止まらないと「もみ消し」と書かれる）
  - 報道されると：ご祝儀−20〜30%、取組の力−1〜2、タニマチが離れかける・後援会も失望、婚約中なら婚約会見取りやめ・相手の両親が激怒して白紙、結婚していれば妻が実家へ
  - **奈央子が相手のとき**は、彼女の編集部が記事を出そうとする。正直に話せば奈央子が記事を止めてくれる（ただし「次はないから」）
- **十両以上で結婚していると部屋を出て家族と暮らす**（マンション／一軒家）。休むと回復が大きい。子どもが生まれるときは立ち会える。幕下以下に落ちたら部屋に戻る
- 彼女・嫁はイベントでは**全身の絵**（白いカードの上）＋右上に表情
- **服は季節で変わる**（次の場所の月で決まる）：1月・11月は秋冬の私服、3月・5月はお出かけ着（結婚後はふだん着）、7月・9月はデート服（結婚後は家着・ふだん着）
- 優勝のお祝いの言葉は毎回変わる（嫁・彼女・タニマチ・宿敵・祝勝会。全部使い切るまで同じ言葉は出ない。初優勝・連覇は専用の言葉）

### タニマチ（後援者・4人）
ちゃんこ屋「大関」の大将／地元建設会社の社長／老舗旅館の女将／IT企業の若社長

- 勝ち越すと声がかかる。毎場所ご祝儀をくれる
- 3場所続けて会食に行かないと離れていく

### お祝い
十両昇進・新入幕・大関昇進・横綱昇進・幕内優勝のとき、**彼女・嫁 → タニマチ → 宿敵**が一人ずつお祝いに来る（言う人とメッセージが中心）

## 12. 便利機能

- **英語モード**：タイトル右上の「🌐 English」で切りかえ（もう一度押すと日本語）。相撲用語はローマ字（Yokozuna、Yorikiri など）、ご祝儀は Prize money。文章は `en.js` の対訳表で、画面に出るときに訳す。いまは画面まわり（第1段階）まで。イベントの文章は順次英訳

- **オート**：自動で稽古・取組を進める。昇進・優勝・恋愛などで止めるかを選べる。速さも変更可
- **チュートリアル**：新弟子が入門するたびに最初の案内
- **音**：タイトルで ON/OFF、BGMと効果音の音量
- **戻る**：画面上の「‹」ボタン、ブラウザの戻るボタンもゲーム内で一つ前へ（タイトルでは確認あり）
- **データ消去**ボタン
- 共有するとタイトルのイラストが表示される
