# 断髪式イラスト ChatGPT依頼文（まとめ）

使い方：下の各ブロックを1回ずつ ChatGPT に貼って依頼する。R1 は力士ごとに5回（キャラ番号と添付シートを差し替える）。
各依頼には、そのキャラのこれまでのシート（シート0・A など）を一緒に添付すると、同じ人物になりやすい。

```

画像サイズは横長 1536×1024。文字、ラベル、番号、ロゴは一切入れないでください。

【シートR0：断髪式の会場（背景）】
両国国技館の土俵で行われる引退相撲の断髪式の会場を、人物なしで描いてください。

・土俵の中央に、赤い毛氈（もうせん）を敷いた上に、黒い背もたれ付きの椅子が1脚だけ置かれている。椅子は空席。

・この背景は、画面いっぱいに描き込んでください（無地の背景にしない）。
```

## 依頼2〜6：シートR1 力士の断髪式の姿（1人1回・計5回）

`キャラ番号 ○` を 1〜5 に変え、その力士のシートを添付して依頼する。

```
添付したキャラクターシートの力士について、新しいシートを1枚描いてください。

【共通ルール】
・添付シートと同じ画風（日本のアニメ調、やわらかい塗り、くっきりした線）で描いてください。
・添付シートと同じ人物に見えるよう、顔立ち・肌の色・体格をそろえてください。
・画像サイズは横長 1536×1024。
・背景は、ベージュの紙色の無地（#F3ECDC くらい）。模様・床・影の色ムラは入れないでください（足元のうすい接地影だけOK）。
・人物どうし、人物と小物が重ならないよう、間隔をあけて並べてください。
・文字、ラベル、番号、ロゴは一切入れないでください。
・全身のコマは、頭の先から足先まで切れないようにしてください。

【シートR1：断髪式の姿　キャラ番号 ○】
この力士が引退し、断髪式に臨む姿を、上下2段に描いてください。

上段：顔（胸から上、正面）を3つ
 1. 大銀杏を結った顔。目を閉じて、静かに覚悟を決めた表情
 2. 断髪後の顔。髪は短く切りそろえた短髪（ちょんまげなし）。晴れやかな笑顔
 3. 断髪後の顔。短髪で、目に涙をためて、くちびるをかみしめた表情

下段：全身を3つ
 4. 黒の紋付羽織袴（白い羽織紐）を着て、黒い椅子に座っている正面の全身。大銀杏を結っている。両手はひざの上、背筋をのばしている
 5. 4と同じ姿を真後ろから見た全身。大銀杏の髷（まげ）がはっきり見えるように
 6. 断髪後、短髪で紋付羽織袴を着て立っている正面の全身。両手で、切り落とした大銀杏の髷を胸の前に大事そうに持っている

・紋付の家紋は、白い丸の中にシンプルな花の紋。
・椅子と人物は、紙色の背景から切り抜きやすいように、くっきり描いてください。
```
