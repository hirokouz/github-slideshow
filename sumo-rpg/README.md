# 横綱への道（相撲キャリアRPG）プロトタイプ

新弟子として入門し、稽古と本場所をくり返して序ノ口から横綱を目指す育成RPG。`index.html` をブラウザで開けばそのまま遊べます（進行は自動保存）。くわしい仕様は [SPEC.md](SPEC.md)。

- 稽古期間（5日）: 四股・てっぽう・すり足・申し合い・ちゃんこ・休む から選んで育てる。疲れすぎるとけが
- 本場所: 幕下以下は7番、十両以上は15番。作戦（押し／四つ／技の三すくみ）を選び、立ち合いのタイミングでタップ
- 番付: 序ノ口〜前頭は勝ち越し・負け越しで上下。小結・関脇・大関昇進、カド番、2場所連続の好成績で横綱昇進
- 演出: 星取（○●）、決まり手、四色の房、「待った」、場所名（初場所〜九州場所）

バランス目安（シミュレーション）: 上手に育てると約4〜5年（25〜30場所）で横綱。

## 売るための次の一手
1. 5〜10人に遊んでもらい「つい次の場所まで進めてしまうか」を確認
2. 追加要素: 部屋・兄弟子・ライバル力士（何度も当たる宿敵）、化粧まわし集め、引退後に親方として弟子を育てる2周目
3. Capacitor で iOS/Android アプリ化、収益化はリワード広告（けが即回復・稽古1回追加）＋買い切り

`game.html` は Artifact 公開用（html/head タグなし）、`index.html` は単体で動く版です。
