# ほたるナイト（HOTARU NIGHT）プロトタイプ

スマホ向けの「1本指・3分・ローグライト」アクション。`index.html` をブラウザで開けばそのまま遊べます。

- 操作: 画面のどこでもドラッグで移動、攻撃は自動（PCは WASD / 矢印キー）
- 目的: 3分間生きのびて夜明けを迎える。2:30 にボス「夜の主」
- フック: 灯り（視界）が少しずつ縮み、敵が落とす光の粒で広がる
- 成長: レベルアップごとに3択の強化（10種）、ラン後に「花の蜜」で永続強化（4種）

## 売るための次の一手
1. まず身近な5〜10人に遊んでもらい「もう1回」と言うか確認（継続率の代わり）
2. 面白さが確認できたら Capacitor で iOS/Android アプリ化
3. 収益化: リワード広告（復活・蜜2倍）＋広告削除の買い切り課金
4. 内容追加: ステージ（夜の場所）とキャラ（ほたるの種類）を増やす

`game.html` は Artifact 公開用（html/head タグなし）、`index.html` は単体で動く版です。
